# chat-logger

Saves your conversations with your favorite AI (chat/claude/gemini) in a json file locally. Only verified it works for Mac. 

1. Clone this repo to `~/projects/chat-logger`. Note: chats will land `log_root` from `settings.yaml`, so modify if necessary.
2. `cd ~/projects/chat-logger && ./install.sh`
3. Chrome → `chrome://extensions` → Developer mode ON → Load unpacked → this folder

I use this paired with some other code to generate Anki flashcards automatically. Go to [anki-flashcards](https://github.com/MaxGonzalezSaez-Diez/anki-flashcards) to see how to install anki and what to do to automatically convert your chats into flashcards.
