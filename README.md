# read_chat_gui

Saves ChatGPT / Claude / Gemini chats as JSON on your Mac.

1. Clone this repo
2. `cd read_chat_gui && ./install.sh`
3. Chrome → `chrome://extensions` → Developer mode ON → Load unpacked → this folder
4. Chats land in `log_root` from `settings.yaml` (default `~/Library/Application Support/read_chat_gui/chats`)

Want Anki flashcards from those chats? Use [flashcard-qa](https://github.com/MaxGonzalezSaez-Diez/flashcard-qa).
