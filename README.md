# chat-logger

Saves ChatGPT / Claude / Gemini chats as JSON on your Mac.

1. Clone this repo to `~/projects/chat-logger`
2. `cd ~/projects/chat-logger && ./install.sh`
3. Chrome → `chrome://extensions` → Developer mode ON → Load unpacked → this folder
4. Chats land in `log_root` from `settings.yaml`

Want Anki flashcards from those chats? Use [anki-flashcards](https://github.com/MaxGonzalezSaez-Diez/anki-flashcards).
